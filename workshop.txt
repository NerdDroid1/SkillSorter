description=Player friendly auto-sorting for Project Zomboid. Name one crate Input, then nearby crates Food, Clothes, Mech, Weld, Agri, Books, Med, Sew, Elec, Guns, Weps, Carp, Surv, or Misc. Drop mixed loot into an Input crate and the server routes items into matching containers. Supports forgiving names like Food, food, [Sort:Food], or sort:food. Combines practical categories such as food+cookware, clothes+bags+armor, animals+farming, and all vehicle parts into Mechanics. This mod is version 1 and has been tested on a live production server. This is server side mod and the client will need to download it but nothing will execute on their client for this mod.  There shouldn't be a noticeable spike is resource usage on your server (this depends on what plan you have).  If you have problems or issues please reach out to my through the PZ Discord.  I'll update and change this as needed.  FULL DISCLOSURE - PZ has over 4,000 items and AI was for inputting the base.ItemNameHere but everything else was written by me.  Adding 4,000 items without the use of AI help would have taken a very long time.
